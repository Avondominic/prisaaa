# assets

Drop your own files in these folders, then point to them in `js/config.js`.

| folder      | what goes here                                   | config key        |
|-------------|--------------------------------------------------|-------------------|
| `cats/`     | one cat per mood (neutral, happy, angry, shock, love) — gif / webp / png / mp4 | `cats`            |
| `goofy/`    | the 3 goofy images for the birthday reveal       | `reveal.goofy`    |
| `memories/` | your real photos for the scrapbook               | `memories`        |
| `music/`    | the song, saved as `song.mp3`                    | `song.src`        |
| `fonts/`    | self-hosted fonts (no need to touch)             | —                 |

Everything currently in `cats/` is a **placeholder** marked "PLACEHOLDER".

Tip: short looping clips as `.mp4` are 5–10× smaller than the same `.gif`,
and they play muted and inline on phones.
